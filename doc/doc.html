Product article

Genesis Artvision Engine is desktop software from ANSNEW TECH. You do not import clips, write a script, or pick a beat of music. You press Generate. The factory rolls a seed, chooses an art engine and a visual style, paints every frame procedurally, writes a soundtrack, and pipes the result into FFmpeg as an MP4.

That is the whole promise: invention, not assembly. The same program can emit a cosmic particle field, a slow alphabet lesson a child can repeat, or a documentary HUD about a telescope. Nothing in the finished file is downloaded as stock video. Pictures for kids words are drawn locally. Voice is Windows text-to-speech when it is available, otherwise an offline voice.

The idea

Most “AI video” tools send your prompt to a cloud model and wait for pixels to come back. Genesis is the opposite shape. It is a random art video factory. Random does not mean chaotic. It means a deterministic integer seed expands into a full project specification: resolution, duration, palette, motion, lesson plan, camera, grade, and audio profile.

If you run the same seed with the same duration, resolution, and frame rate, you get the same film. History in the GUI stores that seed so you can reprint a video the way a print shop reprints a plate.

The factory is useful in three jobs at once:

  • Abstract motion design — particles, galaxies, waves, and tunnels that feel authored, not like a screen saver.
  • Kids learning videos — alphabet, dictionary (spell a word and say what it means), and real-world add / take-away math, spoken slowly.
  • Science explainers — infographic HUD pieces with a calm documentary narrator.

Who it is for

Creators who need a stream of original, license-clean shorts without a footage library. Parents and teachers who want simple on-screen lessons. Anyone who wants a documentary-style science clip without filming. Developers who want a local pipeline they can extend with a new engine instead of a new API key.

It is not a timeline NLE. You do not trim clips on a track. You choose (or randomize) an engine and a style, set length and size, and let the edit brain pace the shots.

How a video is born

Every generate pass follows the same spine.

  1. Seed. A new integer, or one you type, or one replayed from History.
  2. Randomizer. Builds a ProjectSpec: engine, style, palette, per-engine parameters, duration, fps, resolution.
  3. Optional advisor. If OpenRouter is enabled, a JSON creative direction may bias theme, briefs, and on-screen titles. It never paints the movie in the cloud.
  4. Lesson or topic. Kids engines build a shared lesson for picture and voice. The explainer builds a science topic the same way.
  5. Offline pictures. Word cards and suggested scenes are drawn with Pillow on disk.
  6. Audio. Procedural music, kids narration, or documentary speech, written as WAV.
  7. Render. Each frame is drawn, graded, faded, then piped as raw RGB into FFmpeg with the WAV.
  8. Output. An MP4 (and usually a thumbnail JPEG) lands in output/. Temp files are cleaned on success.

The GUI stays responsive because generate runs on a worker thread. Progress shows phase, seed, engine, and — when the advisor is on — what the offline illustrator is drawing.

Kids learning, in detail

Kids videos are meant to teach something a child can say back. Three lesson families share the same slow voice:

Alphabet

One letter, its sound, a word that starts with that letter, and a one-sentence meaning. Example: “Letter A. A says /a/ as in apple. A is for apple. An apple is a fruit you can eat. Say apple.”

Dictionary

Spell the word out loud with pauses (C. A. T.), then the meaning, then “Say cat.” The picture is that word, not a random first letter from other words.

Real-world math

Tiny add and take-away stories from daily life: apples in a basket, birds in a tree, cars on the road. The voice counts the answer slowly (1. 2. 3.) while the screen shows the equation and the objects. It is not abstract algebra.

A hard rule holds the lesson together: letter, word, caption, voice, and picture must agree. The app will not show B, say “M is for moon,” and draw a sun on the same beat. Optional AI suggestions may flavor a picture brief only when they still name the teaching word.

Voice is slow on purpose. Kids SSML uses a slow rate, pauses after single letters and numbers, and keeps one teaching line plus a short cheer so a child can follow. On Windows, SAPI (typically a female voice when installed) is cached under data/ai_voice/. Elsewhere, a procedural voice is used.

Layout is a broadcast kids grid: title, stage, picture card, caption. The letter lives in the stage. Captions are not stacked on top of the glyph. Shot grammar is anticipate → pop → hold → picture → hold → celebrate, so nothing flashes every frame.

Science explainers

The infographic engine is the flagship “serious” look. A topic is chosen (or randomized), then segmented like a short documentary: headline, body, schematic, HUD metrics. Audio is a separate documentary path — slower, lower pitch than kids TTS, mixed over a restrained bed.

Use style documentary or leave Random; that style prefers the explainer. You still get procedural pictures, not licensed B-roll.

Styles and finishing

Seven named styles bias glow, speed, contrast, density, and which engines they like:

  • abstract — open field, any engine.
  • cosmic — galaxy, particles, tunnel; slower drift, more glow.
  • minimal — quieter density; waves and tunnels.
  • organic — waves and galaxies, softer contrast.
  • digital — faster, higher contrast particles and tunnels.
  • playful — prefers the three kids engines.
  • documentary — prefers the explainer, then space-like abstracts.

After the engine draws a frame, a shared finish pass can apply grade, vignette, grain, a gentle push-in, and master fades. Kids engines lock to a broadcast grade: static camera, no grain soup, readable type. The “edit brain” gives abstract engines director time and beat pulse so they do not feel like a looped GIF.

Sound and voice

There is no requirement to drop MP3s into a folder. The factory writes WAV at 44.1 kHz.

  • Abstract: procedural pads, pulses, and optional mix with files in assets/music if you add them.
  • Kids: soft pad, letter chimes, and slow narration aligned to lesson segments.
  • Documentary: calmer speech mixed under a quieter bed.

If audio generation fails, the video can still encode silent. Check logs/. Disable audio in the GUI or with --no-audio when you only need picture.

Optional AI advisor

OpenRouter is off by default. When you turn it on, it is a creative director, not a renderer. It returns JSON: possible lesson theme, focus words, short voice lines, image briefs, overlay titles. Then:

  1. The offline illustrator paints those briefs with Pillow into data/ai_scenes/.
  2. Kids lock still rejects a brief or voice that teaches the wrong word.
  3. Same seed hits a disk cache under data/ai_cache/ so you are not billed twice for a reprint.

Put OPENROUTER_API_KEY in a root .env copied from .env.example. Never commit .env. Cheapest path: run python main.py --curate once to grow data/ai_catalogs/education.json, then generate offline forever from that catalog.

Per-video advisor: GUI Extras checkbox, or python main.py --generate --ai --engine alphabet_cartoon. If a model returns HTTP 402, add credits or stay on openai/gpt-4o-mini in config.yaml.

Using the app

Requirements

  • Python 3.11 or newer (tested on 3.14).
  • FFmpeg on your PATH (winget install Gyan.FFmpeg on Windows).
  • pip install -r requirements.txt (NumPy, Pillow, OpenCV headless, PySide6, PyYAML, pytest).

GUI

python main.py

The window opens maximized. Set duration, resolution (Full HD and 4K, landscape, vertical, square), fps, count, engine, and style. Random is a valid choice for engine and style. Press GENERATE. Preview updates during encode. History lists finished jobs; you can re-generate from seed. Clean Temporary Files if temp/ grows.

CLI

python main.py --generate
python main.py --generate --count 10
python main.py --generate --engine galaxy --style cosmic --duration 30
python main.py --generate --seed 847293847 --resolution 1920x1080 --fps 30
python main.py --test

--test is a 320×180, 10 fps, 3 second smoke render. --curate only expands education catalogs. --output can redirect the folder.

Config

config.yaml holds default resolution, duration options, bitrate (8M Full HD, 35M 4K), engine list, style list, and the AI block. GUI choices override for that run. Logs go to logs/. SQLite history is data/history.db.

Seeds and history

A seed is the identity of a film. The randomizer uses NumPy’s Generator so the same seed expands the same spec. Filename pattern is along the lines of art_<seed>_<date>.mp4. The database stores seed plus parameter JSON for reprint.

Changing duration or resolution with the same seed is a different movie: timing and layout scale. To clone a hit, match seed, engine (if forced), resolution, fps, and duration.

Each engine subclasses ArtEngine, registers with @register_engine, and returns uint8 RGB frames. The factory owns the order: enrich spec → build lesson/topic → realize local images → audio → render. Kids video and kids audio share one education_lesson dict so they cannot drift apart.

Privacy and what stays local

  • No account. No upload of frames.
  • Kids illustrations: local Pillow, cached as PNG.
  • Kids/documentary voice: Windows SAPI or offline synth — not a paid cloud TTS API.
  • OpenRouter, if you enable it, sends a text prompt about the spec and receives JSON. It does not receive your MP4.
  • API keys live in .env, which is gitignored.

Extending it

To add an engine: new file under app/art/, subclass ArtEngine, implement render_frame, register it, import it from ensure_engines_loaded(), list it in config.yaml and ENGINE_PARAM_SPECS. That is the same path particles and alphabet already use.

Kids content lives in app/art/education_content.py (words, meanings, math stories, voice lines). Word drawings live in app/art/word_images.py. Keep letter and word aligned if you add a theme.

Tests: python -m pytest tests/ -q. A fast picture check: python main.py --test.

FAQ

Why does an old kids MP4 still sound wrong? Files already in output/ are not rewritten. Generate again after the teaching-lock work. Same seed with the new code will rebuild voice and pictures correctly.

Why is kids speech slow? So a child can copy letters and counts. Adult documentary speech stays medium.

Can it make photoreal people? No. The offline illustrator is a stylized painter. That is intentional: no stock, no face models.

Linux / macOS? FFmpeg + Python should render. Kids SAPI is Windows; other platforms use the procedural voice fallback.

Where do I start? Install FFmpeg, pip install -r requirements.txt, python main.py, press Generate. For a learning clip, set engine to ABC Educational or Shapes & Colors and style to Playful.
