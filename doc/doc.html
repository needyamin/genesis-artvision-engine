Product article

Genesis Artvision Engine is desktop software from ANSNEW TECH. You do not import clips, write a script, or pick a beat of music. You press Generate. The factory rolls a seed, chooses an art engine and a visual style, paints every frame procedurally, writes a soundtrack, and pipes the result into FFmpeg as an MP4.

That is the whole promise: invention, not assembly. The same program can emit a picture-book story a child can follow, a classroom how-it-works diagram, or a kinetic brief about something trending this week. Nothing in the finished file is downloaded as stock video. Pictures are drawn locally. Voice is Windows text-to-speech when it is available, otherwise an offline voice.

The idea

Most “AI video” tools send your prompt to a cloud model and wait for pixels to come back. Genesis is the opposite shape. It is a random art video factory. Random does not mean chaotic. It means a deterministic integer seed expands into a full project specification: resolution, duration, palette, motion, story or topic, camera, grade, and audio profile.

If you run the same seed with the same duration, resolution, and frame rate, you get the same film. History in the GUI stores that seed so you can reprint a video the way a print shop reprints a plate.

The factory is useful in three jobs at once:

  • Kids storybook — short picture-book pages with matching text, picture, and voice.
  • Everyday education — classroom diagrams that explain how rain, hearts, lamps, and toasters work.
  • Trending briefs — kinetic type about a current-web topic, with a calm narrator.

Who it is for

Creators who need a stream of original, license-clean shorts without a footage library. Parents who want a bedtime picture book on screen. Anyone who wants a classroom explainer or a weekly-trend clip without filming. Developers who want a local pipeline they can extend with a new engine instead of a new API key.

It is not a timeline NLE. You do not trim clips on a track. You choose (or randomize) an engine and a style, set length and size, and let the edit brain pace the shots.

How a video is born

Every generate pass follows the same spine.

  1. Seed. A new integer, or one you type, or one replayed from History.
  2. Randomizer. Builds a ProjectSpec: engine, style, palette, per-engine parameters, duration, fps, resolution.
  3. Optional advisor. If OpenRouter is enabled, a JSON creative direction may bias theme, briefs, and on-screen titles. It never paints the movie in the cloud.
  4. Lesson or topic. Kids Storybook builds story pages. How It Works and Trending Brief build a shared topic for picture and voice.
  5. Offline pictures. Word cards and suggested scenes are drawn with Pillow on disk.
  6. Audio. Procedural music, kids narration, or documentary speech, written as WAV.
  7. Render. Each frame is drawn, graded, faded, then piped as raw RGB into FFmpeg with the WAV.
  8. Output. An MP4 (and usually a thumbnail JPEG) lands in output/. Temp files are cleaned on success.

The GUI stays responsive because generate runs on a worker thread. Progress shows phase, seed, engine, and — when the advisor is on — what the offline illustrator is drawing.

Three engines

Engines are the “what am I looking at.” Styles are the “how it is graded and moved.” The engine owns the concept — story, diagram, or trend — so Random never mixes a kids story with a ticker brief.

Kids storybook

Kids Storybook is a picture book, not an A–Z drill. Each page has a headline, a body line, a spoken voice_line, and one simple noun for the picture (cat, rain, balloon, train).

A hard rule holds the page together: title, text, voice, and picture must agree. The app will not show a crab, say “Say CAT with me,” and play an alphabet cheer on the same beat. Optional AI suggestions may flavor a picture brief only when they still name the story word.

Voice is slow on purpose. On Windows, SAPI is cached under data/ai_voice/. Elsewhere, a procedural voice is used. Layout is a kids grid: title, stage, picture card, caption.

How it works

How It Works is a short classroom explainer. A process is chosen from an offline catalog, then drawn as a diagram that matches the topic (a heart for heartbeat, a cycle labeled Sun / Cloud / Rain / Sea for the water cycle). Side cards show the step headline, body, and a data point.

Audio is a documentary path — slower, lower pitch than kids TTS, mixed over a restrained bed. Style Classroom is the default look.

Trending brief

Trending Brief is kinetic type about something that feels current on the web this week. The engine paints the brief itself: ticker, headline, fact beats. Style Pulse is the matching look — faster, punchier, neon accents.

Styles and finishing

Three named styles bias glow, speed, contrast, and which engine they like:

  • storybook — warm paper, pastel grade, slow page pacing. Prefers Kids Storybook.
  • classroom — clean board, medium contrast, calm diagrams. Prefers How It Works.
  • pulse — fast, punchy, high energy. Prefers Trending Brief.

If you pick an engine and leave style on Random, the matching look is used. If you pick both by hand, the engine still owns the content; style only changes grade and motion.

After the engine draws a frame, a shared finish pass can apply grade, vignette, grain, a gentle push-in, and master fades. Kids Storybook stays readable: static camera, no grain soup.

Sound and voice

There is no requirement to drop MP3s into a folder. The factory writes WAV at 44.1 kHz.

  • Kids Storybook: soft pad, page chimes, and slow narration aligned to story pages.
  • How It Works / Trending Brief: calmer speech mixed under a quieter bed.

If audio generation fails, the video can still encode silent. Check logs/. Disable audio in the GUI or with --no-audio when you only need picture.

Optional AI advisor

OpenRouter is off by default. When you turn it on, it is a creative director, not a renderer. It returns JSON: possible story or topic title, short voice lines, image briefs, overlay titles. Then:

  1. The offline illustrator paints those briefs with Pillow into data/ai_scenes/.
  2. Each engine still paints its own frames. A story stays a story; a diagram stays a diagram.
  3. Same seed hits a disk cache under data/ai_cache/ so you are not billed twice for a reprint.

Put OPENROUTER_API_KEY in a root .env copied from .env.example. Never commit .env. Cheapest path: run python main.py --curate once, then generate offline.

Per-video advisor: GUI Extras checkbox, or python main.py --generate --ai --engine kids_storybook. If a model returns HTTP 402, add credits or stay on openai/gpt-4o-mini in config.yaml.

Using the app

Requirements

  • Python 3.11 or newer (tested on 3.14).
  • FFmpeg on your PATH (winget install Gyan.FFmpeg on Windows).
  • pip install -r requirements.txt (NumPy, Pillow, OpenCV headless, PySide6, PyYAML, pytest).

GUI

python main.py

The window opens maximized. Set duration, resolution (Full HD and 4K, landscape, vertical, square), fps, count, engine, and style. Random is a valid choice for engine and style. Press GENERATE. Preview updates during encode. History lists finished jobs; you can re-generate from seed. Clean Temporary Files if temp/ grows.

CLI

python main.py --generate
python main.py --generate --count 10
python main.py --generate --engine kids_storybook --style storybook --duration 30
python main.py --generate --engine how_it_works --style classroom
python main.py --generate --engine trend_brief --style pulse
python main.py --generate --seed 847293847 --resolution 1920x1080 --fps 30
python main.py --test

--test is a 320×180, 10 fps, 3 second smoke render. --curate expands offline catalogs. --output can redirect the folder.

Config

config.yaml holds default resolution, duration options, bitrate (8M Full HD, 35M 4K), engine list, style list, and the AI block. GUI choices override for that run. Logs go to logs/. SQLite history is data/history.db.

Seeds and history

A seed is the identity of a film. The randomizer uses NumPy’s Generator so the same seed expands the same spec. Filename pattern is along the lines of art_<seed>_<date>.mp4. The database stores seed plus parameter JSON for reprint.

Changing duration or resolution with the same seed is a different movie: timing and layout scale. To clone a hit, match seed, engine (if forced), resolution, fps, and duration.

Each engine subclasses ArtEngine, registers with @register_engine, and returns uint8 RGB frames. The factory owns the order: enrich spec → build story or topic → realize local images → audio → render. Kids video and kids audio share one education_lesson dict so they cannot drift apart. Topic engines share topic_data.

Privacy and what stays local

  • No account. No upload of frames.
  • Kids illustrations: local Pillow, cached as PNG.
  • Kids/documentary voice: Windows SAPI or offline synth — not a paid cloud TTS API.
  • OpenRouter, if you enable it, sends a text prompt about the spec and receives JSON. It does not receive your MP4.
  • API keys live in .env, which is gitignored.

Extending it

To add an engine: new file under app/art/, subclass ArtEngine, implement render_frame, register it, import it from ensure_engines_loaded(), list it in config.yaml and ENGINE_PARAM_SPECS.

Kids stories live in app/art/storybook_content.py. How-it-works processes live in app/art/how_it_works_content.py. Trend topics live in app/art/trend_content.py. Word drawings live in app/art/word_images.py.

Tests: python -m pytest tests/ -q. A fast picture check: python main.py --test.

FAQ

Why does an old MP4 still look like the previous engines? Files already in output/ are not rewritten. Generate again. Same seed with the new code will rebuild picture and voice.

Why is kids speech slow? So a child can follow the page. Adult documentary speech stays medium.

Can it make photoreal people? No. The offline illustrator is a stylized painter. That is intentional: no stock, no face models.

Linux / macOS? FFmpeg + Python should render. Kids SAPI is Windows; other platforms use the procedural voice fallback.

Where do I start? Install FFmpeg, pip install -r requirements.txt, python main.py, press Generate. For a story, set engine to Kids Storybook and style to Storybook.
