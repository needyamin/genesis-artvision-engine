Product article

Genesis Artvision Engine is desktop software from ANSNEW TECH. You do not import clips, write a script, or pick a beat of music. You press GENERATE VIDEO. The factory rolls a seed, chooses an art engine and a visual style, paints every frame procedurally, writes a soundtrack, and pipes the result into FFmpeg as an MP4.

That is the whole promise: invention, not assembly. The same program can emit a picture-book story a child can follow, a classroom how-it-works diagram, or a kinetic brief from an evergreen or AI-suggested topic. Nothing in the finished file is downloaded as stock video. Pictures are drawn locally. Voice is Windows text-to-speech when it is available, otherwise an offline voice.

The idea

Most “AI video” tools send your prompt to a cloud model and wait for pixels to come back. Genesis is the opposite shape. It is a random art video factory. Random does not mean chaotic. It means a deterministic integer seed expands into a full project specification: resolution, duration, palette, motion, story or topic, camera, grade, and audio profile.

If you run the same seed with the same duration, resolution, and frame rate, you get the same film. History in the GUI stores that seed so you can reprint a video the way a print shop reprints a plate.

The factory is useful in three jobs at once:

  • Kids storybook — short picture-book pages with matching text, picture, and voice.
  • Everyday education — classroom diagrams that explain how rain, hearts, lamps, and toasters work.
  • Trending briefs — kinetic type about an evergreen or AI-suggested topic, with a calm narrator.

Who it is for

Creators who need a stream of original, license-clean shorts without a footage library. Parents who want a bedtime picture book on screen. Anyone who wants a classroom explainer or a weekly-trend clip without filming. Developers who want a local pipeline they can extend with a new engine instead of a new API key.

It is not a timeline NLE. You do not trim clips on a track. You choose (or randomize) an engine and a style, set length and size, and let the edit brain pace the shots.

How a video is born

Every generate pass follows the same spine.

  1. Seed. A new integer, or one you type, or one replayed from History.
  2. Randomizer. Builds a ProjectSpec: engine, style, palette, per-engine parameters, duration, fps, resolution.
  3. Optional advisor. If OpenRouter is enabled, a cached JSON creative direction may bias theme, shot purpose, hierarchy, emphasis, transitions, sound cues, and on-screen titles. It never paints the movie in the cloud.
  4. Lesson or topic. Kids Storybook builds story pages. How It Works and Trending Brief build a shared topic for picture and voice.
  5. Offline pictures. Word cards and suggested scenes are drawn with Pillow on disk.
  6. Editorial plan. Narration measurements and semantic emphasis become a timed shot plan with transitions, camera intent, captions, and audio cues.
  7. Audio. Procedural music and narration are smoothly ducked, limited, and normalized toward the configured loudness target.
  8. Render. Each frame is drawn, moved, transitioned, graded, then piped as raw RGB into FFmpeg with the WAV.
  9. QC and output. Muxed streams, exact frame timing, caption overlap, loudness, silence, clipping, sampled black/frozen frames, and manifest integrity are checked before MP4, SRT captions, JSON manifest, and thumbnail are finalized.

The GUI stays responsive because generate runs on a worker thread. Progress shows phase, seed, engine, and — when the advisor is on — what the offline illustrator is drawing. Speech timing holds each picture until that line of voice finishes, so the next card does not appear while the narrator is still talking.

Three engines

Engines are the “what am I looking at.” Styles are the “how it is graded and moved.” The engine owns the concept — story, diagram, or trend — so Random never mixes a kids story with a ticker brief.

Kids storybook

Kids Storybook is a picture book, not an A–Z drill. Each page has a headline, a body line, a spoken voice_line, and one simple noun for the picture (cat, rain, balloon, train).

A hard rule holds the page together: title, text, voice, and picture must agree. The app will not show a crab, say “Say CAT with me,” and play an alphabet cheer on the same beat. Optional AI suggestions may flavor a picture brief only when they still name the story word.

Voice is slow on purpose. On Windows, SAPI is cached under data/ai_voice/. Elsewhere, a procedural voice is used. Layout is a kids grid: title, stage, picture card, caption.

How it works

How It Works is a short classroom explainer. A process is chosen from an offline catalog, then drawn as a diagram that matches the topic (a heart for heartbeat, a cycle labeled Sun / Cloud / Rain / Sea for the water cycle). Side cards show the step headline, body, and a data point.

Audio is a documentary path — slower, lower pitch than kids TTS, mixed over a restrained bed. Style Classroom is the default look.

Trending brief

Trending Brief is kinetic type built from an offline catalog or optional AI creative direction. The engine paints the brief itself: ticker, headline, fact beats. It does not currently collect or verify live web sources. Style Pulse is the matching look — faster, punchier, neon accents.

Styles and finishing

Three named styles bias glow, speed, contrast, and which engine they like:

  • storybook — warm paper, pastel grade, slow page pacing. Prefers Kids Storybook.
  • classroom — clean board, medium contrast, calm diagrams. Prefers How It Works.
  • pulse — fast, punchy, high energy. Prefers Trending Brief.

If you pick an engine and leave style on Random, the matching look is used. If you pick both by hand, the engine still owns the content; style only changes grade and motion.

After the engine draws a frame, a shared finish pass can apply grade, vignette, grain, a gentle push-in, and master fades. Kids Storybook stays readable: static camera, no grain soup.

The Output panel offers Draft, Standard, and Master edit presets plus caption mode and edit intensity. The shared director uses fitted multiline typography, shot-local easing, narration-aware pacing, true two-scene dissolve/push/flash/page-turn transitions, draw-on diagrams, layered Pulse depth, and separate landscape/portrait/square safe layouts.

Sound and voice

There is no requirement to drop MP3s into a folder. The factory writes WAV at 44.1 kHz.

  • Kids Storybook: soft pad, page chimes, and slow narration aligned to story pages.
  • How It Works / Trending Brief: calmer speech mixed under a quieter bed.

If requested audio generation fails, the export stops instead of silently presenting an unfinished mute file. Disable audio in the GUI or with --no-audio when you intentionally need picture only. Kids and classroom cards hold on screen until that spoken line ends.

Optional AI advisor

OpenRouter is off by default. When you turn it on, it is a creative director, not a renderer. It returns validated JSON for story/topic text, shot purpose, hierarchy, emphasis, transition intent, procedural sound cues, image briefs, and overlay titles. Prompt plans are cached by prompt and model. Then:

  1. The offline illustrator paints those briefs with Pillow into data/ai_scenes/.
  2. Each engine still paints its own frames. A story stays a story; a diagram stays a diagram.
  3. Same seed hits a disk cache under data/ai_cache/ so you are not billed twice for a reprint.

Put OPENROUTER_API_KEY in a root .env copied from .env.example. Never commit .env. The --curate command writes a catalog file, but the current render engines still use embedded catalogs. Runtime public-feed ingestion and cited source provenance belong to the next content-source milestone.

Per-video advisor: check AI advisor in the Output panel, or python main.py --generate --ai --engine kids_storybook. If a model returns HTTP 402, add credits or stay on openai/gpt-4o-mini in config.yaml.

Prompt window

Open Prompt from the studio menu, the footer chip, or Ctrl+P. A new window asks what the film should be. Pick Offline (local plan, no internet) or AI suggestion (OpenRouter writes the plan), choose engine / Full HD or 4K / length, then submit. The factory still paints every frame on this machine. Pictures stay on screen until each spoken line finishes. The same prompt words hash to the same seed.

YouTube upload

You can generate a film and then upload it to your channel with an SEO title, hashtags, tags, and a 1280×720 title card. That path uses Google’s official YouTube Data API (OAuth desktop app + videos.insert / thumbnails.set). It is not a scraper and does not bypass sign-in.

  1. In Google Cloud Console enable YouTube Data API v3 and create an OAuth client of type Desktop app.
  2. Credentials go in either data/youtube/client_secret.json (copy the shape from oauth_client.example.json) or YOUTUBE_CLIENT_ID / YOUTUBE_CLIENT_SECRET in root .env. Both are gitignored.
  3. In the GUI: YouTube → Connect / switch channel… Google opens a browser. If you run several channels, pick the Brand Account whose name matches the one you want — not only your Gmail.
  4. Check Upload to YouTube. Privacy defaults to Unlisted. Kids Storybook is declared Made for Kids. Default quota is about six uploads a day (youtube.daily_limit).

After encode, a result card shows the thumbnail, seed, local path, and either the channel plus a youtu.be link or a short API fix — never a raw 403 blob. If the API is off for that Cloud project, enable it, wait a few minutes, and generate again; the MP4 is already in output/. Wrong channel: Connect / switch and pick a different Brand Account. CLI: python main.py --generate --youtube after you have connected in the GUI.

Dark studio GUI

The Genesis interface uses a balanced two-pane production layout in deep navy and teal. A compact three-column control deck across the top keeps Video, Creative, Editing, Batch, Delivery, and YouTube settings visible without scrolling. Below it, Activity and QC share the workspace with an aspect-correct preview, so the monitor does not overpower the controls. Window geometry and pane positions persist between sessions.

  • File — open output, history, clean temp files.
  • Prompt — write a brief (Ctrl+P).
  • YouTube — connect or switch, which channel, Studio, disconnect.
  • Help — About.

Generate, Pause, Resume, and Stop sit directly below the settings deck. New Prompt, History, Output, and cleanup actions remain visible in the footer. Status is always written as text as well as color. Keyboard controls are Ctrl+Enter generate, Esc stop, Ctrl+Shift+P pause, Ctrl+Shift+R resume, Ctrl+P prompt, Ctrl+H history, and Ctrl+O output. The Prompt editor submits with Ctrl+Enter.

Using the app

Requirements

  • Python 3.11 or newer (tested on 3.14).
  • FFmpeg on your PATH (winget install Gyan.FFmpeg on Windows).
  • pip install -r requirements.txt (NumPy, Pillow, OpenCV headless, PySide6, PyYAML, pytest).

GUI

python main.py

The window opens maximized. Set duration, resolution (Full HD and 4K, landscape, vertical, square), fps, count, engine, style, edit preset, edit intensity, and caption mode. Master defaults to burned captions plus SRT. Preview updates during encode. The result card reports QC and opens the video, captions, or manifest directly. File → History restores the complete stored specification.

CLI

python main.py --generate
python main.py --generate --count 10
python main.py --generate --engine kids_storybook --style storybook --duration 30
python main.py --generate --engine how_it_works --style classroom
python main.py --generate --engine trend_brief --style pulse
python main.py --generate --seed 847293847 --resolution 1920x1080 --fps 30
python main.py --prompt "A bedtime story about a brave orange cat"
python main.py --prompt "Explain how rain is made" --ai
python main.py --generate --edit-preset master --captions both --edit-intensity 1.15
python main.py --generate --youtube --engine how_it_works
python main.py --test

--test is a 320×180, 10 fps, 3 second smoke render. --curate expands offline catalogs. --youtube uploads after encode if a channel is already connected. --output can redirect the folder.

Config

config.yaml holds default resolution, duration options, bitrates, edit presets, loudness target, QC tolerance, engine list, style list, and the AI block. GUI choices override for that run. Logs go to logs/. SQLite history is data/history.db.

Seeds and history

A seed is the identity of a film. The randomizer uses NumPy’s Generator so the same seed expands the same spec. Filename pattern is along the lines of art_<seed>_<date>.mp4. The database stores seed plus parameter JSON for reprint.

Changing duration or resolution with the same seed is a different movie: timing and layout scale. History replay avoids that ambiguity by restoring the complete saved ProjectSpec.

output/  temp/  data/   products, scratch, caches

Each engine subclasses ArtEngine, registers with @register_engine, and returns uint8 RGB frames. The factory owns the order: enrich spec → build story or topic → realize local images → audio → render. Kids video and kids audio share one education_lesson dict so they cannot drift apart. Topic engines share topic_data.

Privacy and what stays local

  • No account. No upload of frames.
  • Kids illustrations: local Pillow, cached as PNG.
  • Kids/documentary voice: Windows SAPI or offline synth — not a paid cloud TTS API.
  • OpenRouter, if you enable it, sends a text prompt about the spec and receives JSON. It does not receive your MP4.
  • YouTube upload, if you enable it, sends the finished MP4 to Google with OAuth you control. Tokens and client_secret.json stay in gitignored data/youtube/.
  • API keys live in .env, which is gitignored. Commit .env.example only.

Extending it

To add an engine: new file under app/art/, subclass ArtEngine, implement render_frame, register it, import it from ensure_engines_loaded(), list it in config.yaml and ENGINE_PARAM_SPECS.

Kids stories live in app/art/storybook_content.py. How-it-works processes live in app/art/how_it_works_content.py. Trend topics live in app/art/trend_content.py. Word drawings live in app/art/word_images.py.

Tests: python -m pytest tests/ -q. A fast picture check: python main.py --test.

FAQ

Why does an old MP4 still look like the previous engines? Files already in output/ are not rewritten. Generate again. Same seed with the new code will rebuild picture and voice.

Why is kids speech slow? So a child can follow the page. Adult documentary speech stays medium.

Can it make photoreal people? No. The offline illustrator is a stylized painter. That is intentional: no stock, no face models.

Linux / macOS? FFmpeg + Python should render. Kids SAPI is Windows; other platforms use the procedural voice fallback.

YouTube said the Data API is not used? Enable YouTube Data API v3 on the same Cloud project as the OAuth client, wait two to five minutes, then generate again. The MP4 is already saved.

Uploads went to the wrong channel? YouTube → Connect / switch channel… and choose the Brand Account, not only Gmail.

Where do I start? Install FFmpeg, pip install -r requirements.txt, python main.py, press GENERATE VIDEO. For a story, set engine to Kids Storybook and style to Storybook.
